# Cria uma nova branch chamada develop
git checkout -b develop

# Envia essa nova branch para o GitHub
git push -u origin develop


....


# 1. Garante que você está na main
git checkout main

# 2. Traz as atualizações da develop para a main
git merge develop

# 3. Envia para o GitHub (Ambiente de Produção no Git)
git push origin main

# 4. Volta para a develop para continuar trabalhando amanhã
git checkout develop

....

Para rodar o sistema em prod e em dev, é necessário clonar o repositório para uma outra pasta dev

Abra o terminal na pasta Projeto_DEV.

Execute: git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)

Renomear commit

Se for o ultimo commit
git commit --amend -m "Sua nova mensagem aqui"

Se for outro commit
git rebase -i 4619b215fda9fb1bb4313351c5481d62bc192910^

Altere no vim do git bash (para inserir aperte i) (para salvar aperte ESC e :wq)

depois faça esse comando para enviar a alteração
